☁️ ربط Firebase (نسخة سحابية)

من غير ربط، البيانات بتتخزن على المتصفح بس (يعني كل جهاز هيبقى بياناته لوحده). اربط Firebase عشان البيانات تتحفظ سحابيًا من غير أي حد أقصى، وتفتح نفس البيانات من أي جهاز.
لو عامل الإعداد ده قبل كده من جهاز تاني، الصق نفس بيانات الإعداد (Config) بالظبط تحت — مش هتحتاج تعمل مشروع جديد.
  1. افتح console.firebase.google.com وسجّل دخول بحساب جوجل بتاعك.
  2. Add project ← اكتب اسم أي حاجة (مثلاً my-cash) ← كمّل الخطوات الافتراضية لحد ما يتعمل.
  3. من القائمة على الشمال: Build ← Firestore Database ← Create database ← اختار أي منطقة قريبة ← Start in production mode.
  4. روح لـ Rules فوق واستبدل الموجود بالنص ده بالظبط، وبعدين Publish:
    rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /cash_treasury/{doc} { allow read, write: if true; } } }
  5. من ⚙️ (جنب "Project Overview") ← Project settings ← تحت "Your apps" دوس على أيقونة الويب </> ← سجّل اسم أي حاجة ← Register app.
  6. هيوريك كود فيه حاجة اسمها firebaseConfig = {...} — انسخ الجزء ده بس (من { لحد }) والصقه هنا تحت.
